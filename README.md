# 金属零部件表面缺陷智能检测与分级系统

> 《制造智能技术》课程设计 —— 基于计算机视觉与机器学习的金属零部件表面缺陷智能检测与分级系统

## 1. 项目简介

面向制造/工业场景（金属零部件质量检测）的 B/S 架构智能应用。系统接收零件表面图像上传，自动完成缺陷检测（定位缺陷区域）、缺陷分类（六类典型缺陷）、质量等级判定（A/B/C），并将检测记录持久化到数据库；同时内置遗传算法对视觉检测阈值进行自适应寻优，实现"检测 → 优化 → 闭环反馈"的参数自整定流程。

## 2. 技术方向覆盖（对应课程所学 ≥3 章）

| 序号 | 技术方向 | 具体实现 | 所在模块 |
|------|----------|----------|----------|
| ① | 计算机视觉技术 | OpenCV 灰度化、高斯滤波降噪、Canny 边缘检测、ROI 缺陷区域提取、轮廓面积计算 | `model/detect_model.py` |
| ② | 机器学习与深度学习技术 | PyTorch CNN 卷积神经网络对缺陷区域六分类（裂纹/夹杂/斑点/压痕/氧化皮/划痕） | `model/detect_model.py` + `train_model.py` |
| ③ | 智能优化算法（运筹优化） | 遗传算法搜索最优视觉检测阈值（canny_low/canny_high/area_min/blur_k），以标注样本命中率为适应度 | `model/grade_decision.py` |

## 5. 快速开始

### 5.1 安装依赖

```bash
pip install -r requirements.txt
```

### 5.2 （可选）训练 CNN 缺陷分类模型

```bash
python train_model.py --epochs 10 --batch_size 64
```

训练完成后生成 `model/best.pt`，系统启动时自动加载 CNN 分类；
未训练时系统自动降级为 OpenCV 视觉规则模式，同样可完成演示。

### 5.3 启动系统

```bash
python app.py
```

浏览器访问 <http://127.0.0.1:5000>

### 5.4 运行自动化测试

```bash
python test_case.py
```

## 6. 功能说明

- **上传检测**：输入零件编号、上传零件图片 → 返回缺陷列表（类别/面积/坐标）、质量等级与标注图。
- **历史质检记录**：查询所有历史检测记录（零件号、等级、面积、缺陷数、时间）。
- **参数查看**：查看当前视觉检测阈值。
- **遗传算法优化**：点击优化按钮，遗传算法基于标注样本迭代搜索最优检测阈值，结果写回检测模块并入库（闭环）。

## 7. 质量分级规则

| 等级 | 判定条件 |
|------|----------|
| A（优） | 缺陷总面积 < 2000 px 且缺陷数 ≤ 2 |
| B（良） | 缺陷总面积 < 6000 px 且缺陷数 ≤ 5 |
| C（不合格） | 其余情况 |

## 8. 数据集说明

- 主数据集：NEU 表面缺陷数据库（东北大学公开热轧带钢缺陷数据集，1800 张 200×200 灰度图，6 类缺陷）。
- 数据增强：水平/垂直翻转、90° 旋转、高斯噪声，扩充至 9000+ 样本。
- 划分：训练 70% / 验证 15% / 测试 15%（分层抽样，随机种子 42）。
